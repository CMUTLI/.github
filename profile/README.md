# Teaching and Learning Innovation at Carnegie Mellon

This is the technical home of Carnegie Mellon University's Office of the Vice
Provost for Teaching and Learning Innovation (TLI). TLI brings together the
[Eberly Center for Teaching Excellence and Educational
Innovation](https://www.cmu.edu/teaching/), the Core Competencies Initiative,
and CMU Online.

We build and run the software and servers behind TLI's services for CMU
instructors and students:

- course requests and provisioning for teaching platforms (e.g., Canvas)
- office hours queues
- syllabus collection
- the Eberly Center's website and programs registration

Some projects live alongside their units: see
[CMUEberlyCenter](https://github.com/CMUEberlyCenter) and
[CMUOnline](https://github.com/CMUOnline).

Learn more about TLI at [cmu.edu/tli-office](https://www.cmu.edu/tli-office/).
